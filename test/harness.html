🧪 PitchView Interactive Test Harness

แอปจริง (index.html) ฝังใน iframe ด้านล่าง — กดปุ่มทดสอบแต่ละข้อแล้วดูผล PASS/FAIL ได้เลย (ทำงานกับ DOM จริงของแอป)

1. Grid Lock + ลากสลับจอ

สมมติการลาก ⠿ จอ 1 → ปล่อยบนจอ 2 (ต้องปลดล็อกกริดก่อน) — สลับด้วย CSS order วิดีโอไม่รีโหลด

2. แถบปุ่ม responsive

เช็คว่า header ใช้ flex-wrap + container query และเมื่อจอแคบ ปุ่มทุกปุ่มยังอยู่ในกรอบที่มองเห็น

3. URL ซิงก์ + ย้อนกลับ/ไปหน้า + Enter

จำลองเว็บเปลี่ยนหน้าเอง → ช่อง URL ต้องอัปเดตตาม / ปุ่ม ◀ ▶ ต้องเดินประวัติได้ / Enter = โหลด

4. Save เลย์เอาต์ Custom

เข้าโหมด Custom → บันทึกไม่พิมพ์ชื่อ 2 ครั้ง = ต้องมีรายการเดียว (แก้บั๊กเดิม "เลย์เอาต์ 2, 3" ซ้ำ)

5. เสียง: หลายจอ + ปกติ + ปุ่มลัด + ล้อเมาส์

โหมดปกติ 1–9 = จอเดียว / สวิตช์เสียงหลายจอ = เปิดหลายจอพร้อมกัน / M = ปิดหมด / ล้อเมาส์บนปุ่ม 🔊 = ปรับเสียง

6. ปุ่มลัด Shift+เลข (ขยายเดี่ยว) + ? (สมุดปุ่มลัด)

Shift+3 ต้องขยายจอ 3 เต็มจอ กด Esc ย่อกลับ / กด ? ต้องเปิด overlay สมุดปุ่มลัด

7. ไฟสถานะ LED

🟢 โหลดเสร็จ = เขียว / โหลดพลาด = แดง — จำลอง event จาก webview

8. ความสว่าง/สีต่อจอ

กด ☀ แล้ว webview ต้องมี filter brightness / ◐ ต้องสลับ saturate

9. โปร่งใส + ธีมสี

สไลเดอร์โปร่งใสต้องส่ง IPC / เลือกธีมต้องเปลี่ยน CSS variable + จำค่า

10. Pop-out payload

กด ⧉ ต้องส่ง URL ปัจจุบันจริง (ไม่ใช่ค่าเก่าในช่อง) ไปให้ main process

11. กันจอทับ + ขอบแม่เหล็ก + เมนู Layout รวมเลย์เอาต์ที่บันทึกไว้

ลากทับจออื่น = โดนดันวางชิดขอบ / ขอบใกล้กัน = ดูดชิดเป๊ะ / ขยายทับ = หยุดที่ขอบเพื่อน / บันทึกเลย์เอาต์แล้วเลือกได้จากเมนู Layout
